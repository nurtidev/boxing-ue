# Роадмап UE-версии

**Решение владельца (2026-10-02):** игра переезжает на Unreal Engine 5. Веб-версия (`nurtidev/boxing`, `web/`)
заморожена и служит **спецификацией**: механика боя, данные ростера, правила, постановка раунда, «ощущение»
удара — всё уже выверено там (CLAUDE.md основного репо), здесь это переносится, а не придумывается заново.

## Что уже есть (S-41)

Ринг и арена (Lumen), ядро интерактивного боя на C++ (паритет с web, `Tools/CoreHarness`), бойцы на Motion
Matching (GASP), удары Mixamo со слоем «руки бьют — ноги ходят», наведение кулака (IK), реакция пружинами,
облик боксёра по углам, ввод клавиатура/геймпад, камера боя, HUD на Canvas.

## Правила работы в этом репо

- Один рабочий каталог на всех (контент GASP/MetaHuman вне git, worktree без него не запустится): у каждой
  роли своя зона файлов; в общих файлах (`BoxingFightGameMode`, `BoxerCharacter`, `BoxingFightPlayerController`)
  — только точечные правки (Edit), перечитывать файл перед правкой, не переписывать целиком.
- Сборка: `Build.bat BoxingUEEditor Win64 Development -Project=…\BoxingUE.uproject -WaitMutex`; DLL занята чужим
  редактором — ждать и повторять, чужие процессы не убивать.
- Ядро: механику менять осознанно; `Tools/CoreHarness/build.cmd` — паритет с web на эталонных сидах.
- Git коммитит продюсер.
